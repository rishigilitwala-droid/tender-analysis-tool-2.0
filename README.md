# Tender Analysis Tool

This app lets you upload PDF, Word, or Excel tender documents and generates AI-powered summary cards.

## Features
- Upload PDF, Word, Excel files
- AI-powered summaries
- Customizable card style, detail level, and fields

## How to Deploy
1. Create a new repository on GitHub (e.g., `tender-analysis-tool`).
2. Add these three files (`app.py`, `requirements.txt`, `README.md`) to the repo.
3. Go to [Streamlit Cloud](https://streamlit.io/cloud).
4. Log in with your GitHub account.
5. Click **New App** → select your repo.
6. Set **Main file path** to `app.py`.
7. Click **Deploy**.
8. Done! You’ll get a public link to share.
